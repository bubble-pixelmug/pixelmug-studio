# Contributing to PixelMug Studio

Thank you for contributing to PixelMug Studio.

## Development setup

1. Install Node.js 20.6 or later.
2. Run `npm ci` from the repository root.
3. Run `npm run build` before starting Studio or running tests.
4. Run `npm test` before opening a pull request.

## Pull requests

- Keep each pull request focused on one change.
- Preserve the existing Chinese and English user-interface behavior unless the change explicitly updates copy or localization.
- Do not commit generated output, runtime logs, local credentials, or `debug/` directories.
- Describe user-visible behavior and validation in the pull request.

## Reporting issues

Use GitHub Issues for reproducible bugs, feature requests, and documentation corrections. Include the Studio version, operating system, device model, and concise reproduction steps when relevant.
